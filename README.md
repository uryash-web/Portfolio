# Yash M - Portfolio

Personal developer portfolio showcasing Machine Learning pipelines, software engineering projects, interactive AI assistant, and a live real-time Weather Forecaster.

## Live Demo
Deployed with Vercel.

## Features
- **Featured Projects**: Filter and search through all 5 projects with live links to repositories.
- **Interactive AI Assistant**: Built-in assistant to answer questions about projects, technical skills, and coursework.
- **Live Weather Forecaster**: Real-time city weather query powered by Open-Meteo & OpenWeatherMap APIs.
- **Theme Support**: Seamless dark/light theme toggle respecting system preferences.
- **Zero-Dependency Architecture**: Lightweight, accessible, and fast pure HTML5, CSS3, and vanilla JavaScript.
